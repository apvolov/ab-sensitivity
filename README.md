# A/B testing on game metrics

Исследовательский проект о снижении дисперсии в A/B экспериментах на игровых метриках при неполной предэкспериментальной истории пользователей.

## Что внутри

- `ab_sensitivity/` — подготовка набора World of Warcraft Avatar History, симулятор и методы анализа.
- `scripts/` — запуск экспериментов, подбор параметров и построение графиков.
- `tests/` — автоматические проверки методов.
- `results/` — сохраненные результаты расчетов и рисунки.
- `data/` — место для исходного набора WoWAH; сам набор в репозиторий не включен.
- `docs/source-materials/` — схемы, отчет по проекту и справочные материалы.

## Основные результаты

Эксперименты проведены на реальных характеристиках WoWAH в полусинтетической постановке: распределение метрики и связь периодов взяты из наблюдений, а эффект задается при формировании групп.

| Процедура | Уровень значимости | Мощность при эффекте 5% | Мощность при эффекте 10% | Остаточная дисперсия |
|---|---:|---:|---:|---:|
| Без коррекции | 5,2% | 17,2% | 50,4% | 1,000 |
| CUPED | 5,0% | 32,8% | 83,0% | 0,453 |
| Линейная коррекция | 4,7% | 35,4% | 86,4% | 0,410 |
| CUPAC | 4,2% | 45,8% | 85,8% | 0,377 |

Средние значения относятся к девяти окнам с февраля по октябрь 2008 года. CUPAC рассчитан только для отдельного окна 1 марта 2008 года при 120 повторах; его показатели не следует напрямую трактовать как усредненный результат по девяти окнам.

## Подготовка окружения

Рекомендуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Положите `wowah_data.csv` в `data/` или задайте путь к нему:

```powershell
$env:WOWAH_CSV = "C:\path\to\wowah_data.csv"
```

Описание источника данных и ожидаемой схемы находится в [`data/README.md`](data/README.md). Данные не хранятся в Git из-за объема и условий распространения.

## Запуск

Команды выполняются из корня проекта.

```powershell
# синтетический пилот
python scripts/run_pilot.py 1 200
python scripts/run_pilot.py 2 200

# один запуск на реальных данных
python scripts/run_wowah.py 0.10 150

# сетка по девяти окнам и трем размерам эффекта
python scripts/run_grid.py 2000 plain,cuped,linreg

# CUPAC на отдельном окне
$env:EFFECTS = "0.05"
python scripts/run_grid.py 120 cupac 2008-03-01

# подбор параметров и анализ ковариат
python scripts/tune_boost.py 2008-06-01
python scripts/compare_covariates.py 2008-06-01

# построение рисунков
python scripts/make_figs.py
```

Для запуска проверок:

```powershell
pytest -q
```
