## World of Warcraft Avatar History

Набор собран наблюдением за игровым миром World of Warcraft (сервер Light's Hope)
с января 2006 по январь 2009 года: раз в десять минут фиксировались персонажи,
находившиеся онлайн, вместе с их уровнем, расой, классом, гильдией и зоной.

Источник: https://www.kaggle.com/datasets/mylesoneill/warcraft-avatar-history
Статья о наборе: Lee Y.-T., Chen K.-T., Cheng Y.-M., Lei C.-L. World of Warcraft
Avatar History Dataset. MMSys 2011, pp. 123-128. DOI: 10.1145/1943552.1943569

Нужен файл `wowah_data.csv` со столбцами:

    char, level, race, charclass, zone, guild, timestamp

Положите его в эту папку либо укажите путь переменной окружения:

    export WOWAH_CSV=/путь/к/wowah_data.csv

## Проверка перед работой

    python -c "from ab_sensitivity.wowah import peek; peek('data/wowah_data.csv')"

Выводятся имена столбцов и первые строки. Если формат отличается, поправьте
`CFG` в `ab_sensitivity/wowah.py`: имена столбцов, формат метки времени и
интервал опроса.

Интервал опроса в используемой версии проверен по данным: медиана интервала между
соседними записями одного персонажа 593 с, 88% интервалов в диапазоне 500-800 с.

## Кэш

При первом запуске журнал сворачивается в суточную таблицу `data/daily.parquet`
(около 691 тыс. строк). Дальше она читается с диска. Удалите файл, чтобы пересчитать.
