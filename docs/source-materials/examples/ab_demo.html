Откуда берутся числа

Поправка убирает из шума часть, предсказуемую по прошлому, но только у игроков с историей. Если доля игроков с историей равна h, а связь с прошлым равна ρ, остаточный шум составляет долю от исходного

h (1 − ρ²) + (1 − h)

Песочница использует упрощенную модель с нормальным шумом, поэтому тяжелые хвосты здесь не видны. Расчет по формуле можно проверить прямым моделированием.
