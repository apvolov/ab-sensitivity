# Исходные материалы

Здесь собраны справочные материалы к исследовательскому программному проекту.

- `examples/` — HTML-демо A/B эксперимента.
- `diagrams/` — исходник и PDF IDEF0 схемы.
- `reports/` — промежуточный отчет ВКР.
- `reference-pdfs/` — справочные PDF по поправке на предысторию и по нескольким признакам.
- `legacy-code/` — вспомогательные скрипты и результаты из верхнего уровня переданного архива, сохраненные отдельно от актуального пакета.

Основная версия расчетного кода находится в `ab_sensitivity/` и `scripts/`, а сохраненные результаты — в `results/`.
